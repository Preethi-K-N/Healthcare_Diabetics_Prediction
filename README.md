# 🏥 MediRisk AI – Healthcare Risk Prediction

> AI-powered patient risk assessment using a stacking ensemble (RF + LightGBM + XGBoost + CatBoost).  
> **94.8% Accuracy · 91.2% F1 Score · 97.5% ROC-AUC** on 17,675 patient records.

---

## 📁 Project Structure

```
healthcare_project/
├── config.py              # Central config (paths, seeds, feature names)
├── 01_load_data.py        # Load & inspect the dataset
├── 02_eda.py              # Exploratory Data Analysis + plots
├── 03_preprocess.py       # Encoding, scaling, train/test split
├── 04_train.py            # Stacking ensemble training with SMOTE
├── 05_evaluate.py         # Full evaluation + baseline comparison
├── app.py                 # Streamlit phone-style web app
├── requirements.txt       # All Python dependencies
├── data/
│   └── healthcare_dataset.csv   ← Place your dataset here
└── models/
    ├── healthcare_model.pkl     (generated by 04_train.py)
    ├── scaler.pkl               (generated by 03_preprocess.py)
    └── splits/                  (numpy arrays from 03_preprocess.py)
```

## ⚙️ Setup

### 1. Clone / open in VS Code
```bash
code healthcare_project
```

### 2. Create & activate virtual environment
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Add your dataset
Place your CSV file at:
```
data/healthcare_dataset.csv
```
The CSV must contain the columns listed in `config.py → FEATURE_COLUMNS` plus a `Diagnosis` column (0 = No Risk, 1 = At Risk).

---

## 🚀 Running the Pipeline

Execute each step in order:

```bash
# Step 1 – Inspect the dataset
python 01_load_data.py

# Step 2 – Exploratory Data Analysis (saves plots to data/eda_plots/)
python 02_eda.py

# Step 3 – Preprocessing (encodes, scales, splits, saves scaler + numpy arrays)
python 03_preprocess.py

# Step 4 – Train the stacking ensemble (saves models/healthcare_model.pkl)
python 04_train.py

# Step 5 – Full evaluation with baseline comparison (saves plots to data/eval_plots/)
python 05_evaluate.py

# Launch the Streamlit app
streamlit run app.py
```

> ⏱ Training (~step 4) can take **10–30 minutes** depending on your CPU.

---

## 🖥️ Streamlit Web App

After running steps 1–4, launch:
```bash
streamlit run app.py
```
Open **http://localhost:8501** in your browser.

The app will open in a mobile-style dark UI where you can:
- Enter patient demographics and clinical measurements
- Click **Run Health Analysis** to get a risk score
- See a radar chart, risk drivers bar chart and personalised recommendations
- Download a PDF health report

## 🧠 Model Architecture

```
INPUT (15 features)
        │
   ┌────┼─────────────┬──────────┐
   ↓    ↓             ↓          ↓
  RF   LightGBM    XGBoost   CatBoost
   └────┴─────────────┴──────────┘
                 │
       Logistic Regression  ← Meta-learner
                 │
            PREDICTION
```

**Key techniques:**
- SMOTE inside each CV fold (prevents data leakage)
- 5-fold Stratified Cross-Validation
- StandardScaler fitted on training data only
